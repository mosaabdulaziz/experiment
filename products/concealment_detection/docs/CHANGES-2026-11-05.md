**Two of these were live production bugs in the shared sidecar engine, found only by the
repo-level contract tests:**

1. `svr_windows` was never written, so every archive completion raised `KeyError: 'pts_start'`.
2. Coverage was read *after* `start-sr` was emitted and used the un-rounded floats, so the
   window was wrong (`993.0,1005.0` where `94.25,106.25` was correct, then `132.35,144.35`
   where `132.75,144.75` was correct). DeepStream receives **integer** seconds; the snapshot is
   now taken before the emit under `_SVR_EMIT_LOCK` and the recorded window uses the rounded
   pair actually handed to the pipeline.

## One test I rejected

An implementation agent added a test asserting that **any** quality-driven `[missing]` reset must
also flush the reach/feature history. That contradicts the documented tolerance
(`degrade_max_s`, and now `MAX_OBSERVATION_GAP_S`): a single skipped inference is normal and its
evidence must survive. Implementing it would have reset every real stream that drops one frame and
destroyed recall, so the test was rejected rather than satisfied. The behaviour is now pinned from
both sides instead — `test_monitor_resets_evidence_across_gaps` (five gap kinds must reset) and
`test_one_frame_absence_bridges_the_sequence_but_credits_no_time` (a sub-threshold blip must not).

The same agent's sidecar design (`_SVR_COMPLETION_SLOTS` semaphore) raised
`NameError: name '_SVR_COMPLETION_SLOTS' is not defined` and was replaced by the bounded queue and
lazy worker path that already existed in `svr.py`.

- **`AT_BODY` active-hand precedence (`concealment/state_machine.py`)**: Active-hand `HIDDEN`, `AT_BODY` hold accumulation, and `RETURNED` are now evaluated before `_can_transfer`, preventing `hand_transfer` from transferring away a concealing hand whenever the other hand rests near the hips. - **`zone_free` precedence (`concealment/zones.py`)**: `find_containing_zone` now returns `_ZONE_FREE_POLYGON` immediately when `camera_zones.zone_free` is `True`.
